# PhotoRental (Java)
Сервис по аренде фото и видео-оборудования (в том числе и расходников, таких как аккумуляторы и SD карты).

Приложение позволяет клиентам арендовать фото и видеотехнику на различный срок.

## Функционал
Для различных пользователей функционал разный, так как приложение рассчитано как на клиентов, так и на сотрудников.

### Для клиента:
- Возможность арендовать оборудование на определённый срок
- Продлить время аренды, если именно на эту позицию есть свободное время
- При аренде старается подбираться наилучшее оборудование, доступное прямо сейчас на складе

### Для менеджера:
- Возможность выдать/принять оборудование у клиентов
- Изменять состояние техники (обязательные комментарии для обоснования причины)

### Для администратора:
- Все возможности менеджера
- Возможность управлять пользователями и каталогом техники
- Возможность списывать оборудование со склада, если оно не подлежит ремонту (тоже с обоснованием причины)

## Структура

### `model`
Модели предметной области:
- `User` (абстрактный) — базовый пользователь, от него наследуются `AdminUser`, `ManagerUser`, `CustomerUser`
- `UserRole` — роль пользователя (`ADMIN`, `MANAGER`, `CUSTOMER`)
- `Equipment` — единица техники (камера, объектив, свет и т.д.)
- `EquipmentCategory`, `EquipmentStatus`, `EquipmentCondition` — категория, текущий статус и физическое состояние техники
- `EquipmentNote` — заметка о причине изменения состояния техники (для истории/аудита)
- `Rental` — запись об аренде: кто, что, на какой срок
- `RentalStatus` — статус аренды (`BOOKED`, `ACTIVE`, `RETURNED`, `OVERDUE`)

### `repository`
Интерфейсы и in-memory реализации хранения данных (`EquipmentRepository`, `UserRepository`, `RentalRepository`, `EquipmentNoteRepository`). 

Отделяют логику бизнеса от конкретного способа хранения.

### `service`
Бизнес-логика приложения:
- `EquipmentService` — управление каталогом техники, подбор лучшего доступного экземпляра, изменение состояния с обязательным обоснованием, генерация серийных номеров
- `UserService` — регистрация пользователей
- `RentalService` — бронирование, выдача, приём и продление аренды с проверкой пересечения дат

### `concurrent`
`RentalOverdueProcessor` — многопоточная обработка коллекции активных аренд для пометки просроченных, с именованными потоками и логированием.

## Тесты
